# Bart van Zeist - portfolio

Forked van [bchiang7/v4](https://github.com/bchiang7/v4)

Built with Gatsby 5, React 19, TypeScript 5, and styled-components 6.

## Requirements

- Node.js 24.14.0 via `nvm use`
- Corepack-enabled Yarn 4.12.0

## Install

```sh
corepack enable
yarn install
```

## Development

```sh
yarn develop
```

## Production build

```sh
yarn build
```

The static site output is generated in `public/` and can be deployed to any static host.

## Local preview

```sh
yarn serve
```

## Lint

```sh
yarn lint
```
