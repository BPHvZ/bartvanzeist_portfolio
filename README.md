# Bart van Zeist - portfolio

Forked van [bchiang7/v4](https://github.com/bchiang7/v4)

## Requirements

- Node.js 18.7.0 via `nvm use`
- Corepack-enabled Yarn 3.2.0

## Install

```sh
corepack enable
yarn install
```

## Development

```sh
yarn develop
```

## Production build

```sh
yarn build
```

The static site output is generated in `public/` and can be deployed to any static host.

## Local preview

```sh
yarn serve
```
